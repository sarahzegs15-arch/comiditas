# 🥕 Comiditas

Juego didáctico para bebés (2–3 años) para iPad con iOS 12.5.x. Funciona **sin internet** una vez instalado. Fondo oscuro y **sonidos muy suaves y tiernos**.

## Mini juegos (menú de la izquierda)
- 🥕 **¿Qué le gusta comer?** Cada animalito pide su comida (pollito–maíz, gatito–pescado, perrito–hueso, elefante–cacahuate, unicornio–zanahoria, león–carne). Se arrastra (o se toca) la comida correcta. Si no es, el animalito mueve la cabecita con ternura y, tras 2 intentos, la correcta late suavemente. Al inicio hay un dibujo de ayuda y después solo un "?".
- 🍓 **Contar con la comida:** el animalito pide 1, 2 o 3 frutas (luego hasta 5). Cada fruta se cuenta con voz bajita ("uno, dos, tres") y una notita suave.

## Papás
Arriba a la derecha (mantener ~1 s): 🔈 silenciar (también la voz) · 🔄 reiniciar el mini juego.
Volumen general: `VOL` al inicio de `app.js` (0.35). La voz usa el sintetizador del iPad (si no tiene voz en español instalada, solo se escuchan las notitas).
Para actualizar: reemplaza los archivos del repositorio y sube la versión en `sw.js`.
